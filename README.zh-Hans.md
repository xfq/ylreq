# 彝文排版需求

[English](README.md)

## 摘要

本文整理了彝文于排版上的需求。一方面说明需求事项以明确描述彝文排版之需求与问题；另一方面也提出与既有标准（如Unicode）的对应，冀求本文能更有效地促进实现。

## 绪论

彝族是中国第六大少数民族，人口近千万。彝文是中国少数民族文字中历史悠久且至今仍在使用的文字之一，是彝族文学、历史与文化知识传承的主要载体，也是彝族文化认同的核心。在数字时代为彝文提供良好的排版支持，对于保护和传承彝族文化具有重要意义。

现代彝文是一种音节文字。在现代标准化的北部方言正字法中，每个音节由一个彝文字符表示，词语可以包含一个或多个以空格分隔的音节。彝文没有大小写，也不包含连写文本。彝文内容常常与阿拉伯数字、拉丁字母和中文混排。

早期彝文为表意文字。随着时间推移，大量音节符号被纳入其中，使其转变为一种以表意为主、辅以表音成分的意音文字。目前通行的凉山规范彝文是纯音节文字，而云南规范彝文仍为意音文字。

## 文本方向

### 行文模式

现代彝文应支持水平从左到右的行文模式。默认的行内方向为从左到右，块方向为从上到下。

历史材料可能采用竖排，实现应支持竖排下的彝文，但仍需更多原始资料进行验证。

### 双向文本

在云南、贵州和广西，老彝文通常以水平或垂直方向从左到右书写；在四川，则以水平或垂直方向从右到左书写。新的规范彝文以水平从左到右的方式书写。

## 排版单元

### 字符与编码

Unicode 3.0中正式收录了凉山规范彝文。彝文音节的编码范围为 U+A000–U+A48C，共包含1164个音节（带附加符号的音节分别编码，不能拆分为基本音节和组合附加符号）以及一个叠字标记（U+A015 ꀕ，其名称误写为“YI SYLLABLE WU”）。彝文部首的编码范围为U+A490–U+A4CF，共包含55个部首。

2007年，中国提交了为云南规范彝文编码的提案，但尚未纳入Unicode，也尚未分配码段。

### 字素、词语的分割与选择

字素分割算法应将每个彝文音节作为一个字素簇。
